HỆ THỐNG QUẢN LÝ KHO HÀNG

(Warehouse Management System)


Môn học: Đồ Án Chuyên Ngành

Sinh viên thực hiện: [Tên Của Bạn]

Mục tiêu: Xây dựng hệ thống số hóa quy trình quản lý, nhập/xuất và theo dõi tồn kho theo thời gian thực.

Tổng Quan Kiến Trúc

Mô hình N-Tier (Đa tầng) trên nền tảng .NET Core 8

  • Presentation Layer (Web): ASP.NET Core MVC (Views, Controllers).
  • API Layer: RESTful endpoints hỗ trợ đa nền tảng.
  • Business Logic (BLL): Xử lý nghiệp vụ tập trung (Services).
  • Data Access (DAL): Áp dụng Repository Pattern với ADO.NET (SqlConnectionFactory).
  • Models: Đối tượng thực thể dữ liệu (Product, StockLog...).

Các Chức Năng Chính

  • Quản lý Hệ Thống: Xác thực người dùng, phân quyền an toàn.
  • Quản lý Danh Mục: Khởi tạo & cập nhật thông tin Hàng hóa (SKU), Nhà cung cấp.
  • Quản lý Kho (Stock):
    • Nhập kho (Import) & Xuất kho (Export).
    • Tự động ghi nhận lịch sử biến động (StockLog).
  • Thống kê & Dashboard: Báo cáo tổng quan số lượng, giá trị, cảnh báo tồn kho thấp.

Cơ Sở Dữ Liệu & Hiệu Năng

  • Hệ quản trị CSDL: Microsoft SQL Server.
  • Tối ưu bằng Stored Procedures: Mọi thao tác truy vấn phức tạp (sp_StockDashboard, sp_ImportStock, sp_LowStockReport) được xử lý dưới DB giúp tăng tốc tối đa.
  • Bảo toàn Dữ Liệu: Sử dụng cơ chế Transaction bên trong SQL để đảm bảo tính nhất quán (ACID) khi nhiều luồng nhập/xuất cùng lúc.

Điểm Nổi Bật Của Hệ Thống

  • Repository Pattern & DI: Tách biệt rõ ràng giao diện và truy xuất dữ liệu, dễ dàng mở rộng.
  • Bảo mật cao: Tránh SQL Injection thông qua Parameterized Queries (ADO.NET). Tách rời Web và API.
  • UX Tối Ưu: Phân trang dữ liệu (Paging) và tìm kiếm (Search) tốc độ cao giúp xử lý khối lượng lớn hàng hóa mà không bị giật lag.

Hướng Phát Triển Tương Lai

  • Tích hợp Mobile App: Quét mã vạch (Barcode/QR Code) cho nhập xuất kho qua điện thoại di động nhờ hạ tầng API sẵn có.
  • Hệ thống cảnh báo tự động: Cấu hình gửi Email/SMS khi hàng chạm ngưỡng tối thiểu.
  • Phân tích tài chính (BI): Bổ sung biểu đồ trực quan dòng tiền và chi phí lưu kho.
